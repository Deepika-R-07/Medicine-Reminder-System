# Medicine Reminder System

A web-based **Medicine Reminder System** designed to help users manage their medications, track daily reminders, monitor medicine adherence, and receive AI-powered assistance for medicine-related questions.

The system provides a simple and user-friendly dashboard where users can add medicines, set reminder schedules, track taken and missed doses, view medicine history, and monitor their medication adherence.


Project available at:https://medicine-reminder-app-jeiy.onrender.com
## Project Overview

Managing multiple medicines and remembering their schedules can be difficult, especially when medicines need to be taken at specific times and for specific durations.

The **Medicine Reminder System** provides a centralized platform for managing medication schedules and monitoring adherence.

The system allows users to:

- Register and securely log in
- Add and manage medicines
- Set dosage and reminder times
- Specify medicine start and end dates
- View medicines scheduled for the current day
- Mark medicines as Taken or Missed
- Maintain medicine history
- View medication adherence statistics
- Access an AI-powered health assistant
- Manage their user profile



## Key Features

### 1. User Registration

Users can create an account by providing their basic details.

**Features:**
- User name
- Email
- Password
- Account creation
- Database storage

---

### 2. User Login

Registered users can log into the system using their email and password.

The application uses session management to maintain the user's login state.

**Features:**
- Email and password authentication
- Session-based login
- Unauthorized users are redirected to the login page
- Logout functionality



### 3. Dashboard

After successful login, users are redirected to the main dashboard.

The dashboard provides an overview of the user's medication activity.

### Dashboard Statistics

The dashboard can display:

- Total Medicines
- Today's Medicines
- Active Medicines
- Taken Today
- Missed Today
- Medication Completion Percentage
